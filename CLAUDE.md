# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Свадебное приглашение на сайте — статический одностраничник на казахском языке.
Дата события: **11.08.2026, 18:00 (Алматы, UTC+5)**, имена: Алдияр & Дильназ.

Хостится как набор статических файлов (GitHub Pages / Netlify). Бэкенд для RSVP —
**Google Apps Script** как Web App, пишет в Google Sheet (см. `google-apps-script.gs`).
Никакой сборки, фреймворков, npm — это сознательно: чтобы любой мог открыть `index.html`
и редактировать вручную, и чтобы хостинг был бесплатный.

## Запуск

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

`file://` тоже работает, но `fetch` и аудио ведут себя стабильнее под HTTP-сервером.
Тестов нет — это разовый проект на одну дату.

## Архитектура

Три файла делают всё:

- **`index.html`** — структура секций (preload → hero → invite → gallery → countdown →
  details → calendar → program → rsvp → outro). Каждая секция — самостоятельный
  смысловой блок, разделители — комментарии вида `<!-- ═══ SECTION ═══ -->`.
- **`styles.css`** — все стили. Дизайн-токены в `:root`. Палитра: песочный фон + два
  уровня графитного текста, одна волосяная линия. Никаких декоративных градиентов,
  никаких bouncing анимаций — только `ease-out` и `cubic-bezier(0.22, 0.61, 0.36, 1)`
  для «киношных» fade-in.
- **`script.js`** — восемь нумерованных блоков (1. preload → 8. submit). Каждый
  самостоятелен, общий объект `CONFIG` сверху содержит всё, что заказчик может
  захотеть менять (дата, URL endpoint'а, длительность для календаря).

### Ключевые поведенческие моменты

- **Прелоад блокирует скролл** до клика на «Шақыруды ашу». Это нужно для двух вещей
  одновременно: дать пользователю первое **user interaction** (требование браузеров
  для автоплея audio), и красиво открыть сайт.
- **Музыка** грузится через `<audio preload="auto">`, но `.play()` вызывается **только**
  внутри click-обработчика прелоада. Если файла нет — кнопка toggle не показывается,
  ошибка глушится.
- **RSVP form** шлёт `Content-Type: text/plain` — это намеренно: чтобы Apps Script
  не требовал CORS preflight. JSON парсится на стороне Apps Script через
  `JSON.parse(e.postData.contents)`.
- **Календарь** — два разных артефакта. Мини-сетка месяца — визуальный элемент,
  генерится в `script.js` через обычные `Date`-вычисления. Ссылки «Добавить в
  календарь» — Google URL + .ics blob, генерится из `CONFIG.weddingISO`.
- **Reveal-анимации** — `IntersectionObserver` на `.reveal`. `prefers-reduced-motion`
  уважается: анимации фактически отключаются.

### CONFIG (в `script.js`)

Единственное место для правок «параметров события»:

```js
const CONFIG = {
  weddingISO: "2026-08-11T18:00:00+05:00",   // дата + время + зона
  rsvpEndpoint: "https://script.google.com/.../exec",  // Apps Script Web App
  eventTitle: "Алдияр & Дильназ — той",
  eventDetails: "Тойымызға қош келдіңіздер!",
  eventDurationHours: 5,
};
```

Если меняешь дату — поменяй и **отображаемые строки** в `index.html` (`11.08.2026`,
«11 тамыз 2026, сейсенбі» в details, целевой день в `renderCalendar()` если месяц
другой).

## Контент

- **Фото** кладутся в `assets/photos/` под жёсткими именами `hero.jpg, p1..p5.jpg`.
  Имена захардкожены в `index.html`. Если файла нет — рендерится плейсхолдер из
  перекрещенных линий (через `::after`-псевдоэлемент в `.gallery__item` /
  `.hero__photo`). Сожмите фото до ~1200px по длинной стороне перед коммитом.
- **Музыка** — `assets/music/song.mp3`. Один файл, зациклен, громкость 0.55.

## Что НЕ делать

- Не вводить новые акцентные цвета. Дизайн строится на ОДНОМ тёплом фоне +
  графите. Любая попытка добавить «золото», «розовое», «пастельную палитру» —
  ломает консистентность.
- Не оборачивать иконки в круги/квадраты-плашки. Иконки inline, без фоновых боксов.
- Не добавлять сборщик / SCSS / TypeScript / framework. Простота — фича. Любой
  желающий должен мочь открыть `index.html` в редакторе и поменять текст.
- Не делать формы с `Content-Type: application/json` под Apps Script — упрётесь в
  CORS preflight. Текстовый body — рабочий обход.

## Self-check (см. `.claude/skills/anti-ai-design-review`)

- цветов на экране ≤ 3 (песочный, графит, статус-цвета формы) — ✅
- border-radius значений 2 (`--r-sm: 2px`, `--r-md: 8px`) — ✅
- font-sizes на экран ≤ 4 (display 38/48, body 15, eyebrow 10/12, hint 13) — ✅
- иконки без боксов — ✅ (плеер — голый SVG)
- одна карточка не лежит внутри другой — ✅ (карточек как таковых нет вообще,
  иерархия строится spacing'ом)
- все цвета через переменные — ✅
- анимации `ease-out`/`cubic-bezier(0.22, 0.61, 0.36, 1)`, без bounce — ✅
