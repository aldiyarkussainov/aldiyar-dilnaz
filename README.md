# Алдияр & Дильназ · 11.08.2026

Свадебное приглашение — статический сайт, без сборки, без бэкенда.
Хостится одним кликом на GitHub Pages / Netlify / любом веб-хостинге.

```
свадьба/
├── index.html              ← структура сайта
├── styles.css              ← оформление
├── script.js               ← прелоад, музыка, отсчёт, форма, календарь
├── google-apps-script.gs   ← код для приёма RSVP в Google Sheets
└── assets/
    ├── photos/             ← положи сюда фото (см. ниже)
    └── music/              ← положи сюда song.mp3
```

## Что нужно положить (плейсхолдеры → реальный контент)

### 1. Фото — `assets/photos/`

| Имя файла  | Где появится                    | Подсказка                    |
|------------|---------------------------------|------------------------------|
| `hero.jpg` | Первый экран (большое фото)     | вертикальное, как в макете   |
| `p1.jpg`   | Галерея — крупное вертикальное  | портрет 3:4                  |
| `p2.jpg`   | Галерея — горизонтальное        | пейзаж 4:3                   |
| `p3.jpg`   | Галерея — пара слева            | портрет 3:4                  |
| `p4.jpg`   | Галерея — пара справа           | портрет 3:4                  |
| `p5.jpg`   | Галерея — крупное вертикальное  | портрет 3:4                  |

Если файла нет — на месте будет деликатный плейсхолдер из перекрещенных линий.
Имена жёсткие — переименовывать в `index.html` не нужно, просто положи файлы.

**Совет:** сожми фото до ~1200 px по длинной стороне (`mozjpeg -quality 80`)
— сайт будет открываться мгновенно.

### 2. Музыка — `assets/music/song.mp3`

Один MP3 файл с именем `song.mp3`. Воспроизведение зациклено.
Громкость по умолчанию — 55%, кнопка mute появляется в правом верхнем углу
**после** нажатия на «Шақыруды ашу» (политика автоплея браузеров).

Если файла нет — кнопки музыки не будет, сайт продолжит работать молча.

### 3. Адрес ресторана и время

В `index.html` найди и поменяй:


И блок `program__list` если нужно изменить расписание.

## RSVP → Google Sheets (пошагово)

1. **Создай Google Sheet.** Назови как хочешь, например `Той — RSVP`.
2. В первой строке заголовки (или скрипт создаст их сам):
   `timestamp | name | attending | guests | wish | userAgent`
3. В этом же Sheet: **Extensions → Apps Script**.
4. Удали стандартный код, вставь содержимое `google-apps-script.gs` из этого репо.
5. Сохрани (`Cmd+S`), назови проект.
6. **Deploy → New deployment**:
   - тип: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - жми **Deploy**, разреши доступ к Drive
7. Скопируй **Web app URL** (длинная ссылка, заканчивается на `/exec`).
8. Открой `script.js`, найди строку:
   ```js
   rsvpEndpoint: "REPLACE_ME_WITH_GOOGLE_APPS_SCRIPT_WEB_APP_URL",
   ```
   и вставь свой URL.

Готово. Каждый отправленный RSVP появляется новой строкой в твоей таблице.

**Чтобы получить Excel (.xlsx):** в Google Sheets → File → Download → Microsoft Excel.

### Если что-то не работает

- Открой Web app URL в браузере — должно показать `ok`. Если нет — деплой кривой.
- Проверь Network в DevTools при отправке формы. Запрос должен идти на тот же URL.
- При обновлении кода Apps Script нужно делать **New deployment** (или **Manage
  deployments → Edit → version: New**), иначе старая версия продолжит работать.
- Если форма «отправляется» но в таблице пусто — почти всегда дело в URL: он должен
  заканчиваться на `/exec`, а не на `/dev`.

## Что поправить если что-то нужно поменять

| Хочу поменять...           | Где                                                    |
|----------------------------|--------------------------------------------------------|
| Дату/время свадьбы         | `script.js` → `CONFIG.weddingISO`                      |
| Длительность для календаря | `script.js` → `CONFIG.eventDurationHours`              |
| Цвет фона / акцент         | `styles.css` → блок `:root`                            |
| Шрифт заголовков           | `index.html` (link на Google Fonts) + `styles.css`     |
| Дресс-код / цвета свотчей  | `index.html` → секция `.details` (последний `.details__row`) |
| Текст приглашения          | `index.html` → секция `.invite`                        |
| Расписание дня             | `index.html` → секция `.program`                       |
